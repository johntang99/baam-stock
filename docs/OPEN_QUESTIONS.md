# OPEN QUESTIONS · Phase 0

Contradictions, gaps and assumptions found while implementing Phase 0 (plan-0.7 / contract-0.7 → **contract-0.7.1** / phases-0.7).
Each item states the default we took so work could continue. **Needs a decision** = please confirm or change before Phase 1.

SPY lists on NYSE Arca; ^VIX is a Cboe index with no NBBO. | Bumped to **contract-0.7.1**: added `etf`, `index`, `ARCX`, `XCBO`.
