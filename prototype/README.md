# prototype/ · 可交互 HTML 原型

**模拟数据（MOCK）**：所有行情、事件、预测、模型成绩均为虚构，仅用于产品确认与开发参考。

## 这是什么

这是**可点击的模拟原型**，用来确认页面、流程和字段，不是真实系统：不连接数据源，不跑模型，所有按钮都只驱动模拟数据。真实系统按 DEVELOPMENT_PHASES 用 Next.js + Supabase + Python 实现，原型的页面与字段是其参考。

## 打开方式
- 直接双击 `index.html`（无需服务器、无外部依赖），或
- `cd prototype && python3 -m http.server 8080`，浏览器打开 http://localhost:8080

## 页面与路由（hash 路由）
| 页面 | 路由 | 主要交互 |
|---|---|---|
| 公司监控 | `#/monitor` | 四家卡片 → 详情/预测/事件；数据质量与运行状态徽标、"最近有效"时间（AVGO 演示降级） |
| 股票详情 | `#/stock/{NVDA|AMD|AVGO|MU}` | 切换证券、主动刷新（模拟入队）、证据四类时间、受限复核证据、行业表现图（悬停/表格视图）；快照有效期、估值背景行（只作背景）；**预测与实际**卡片：今日槽位（08:30/10:00/11:30/13:00/14:30/16:30 ET）两条曲线叠加（实际 vs 预测中位路径 + p10–p90 区间）、槽位结果表、当日/近 20 日/上线以来准确率 |
| 股票详情 · ① 信息采集 | `#/stock/{ticker}/collect?item=` | 第 1 步：顶部三步条（采集 → 推理 → 预测）；计数卡片（可点击筛选）；渠道 × 类别矩阵；本次轮询的来源与状态；全部采集条目长列表（保留/去重/排除/待核/抓取失败及原因、四类时间），可按渠道、类别、处置筛选和搜索 |
| 股票详情 · ① 信息采集 · 用户补充 | `#/stock/{ticker}/collect` 顶部"＋ 添加信息" | 提交链接/文本/文件，多选类别或交给系统；演示核验结果（原始来源已核实 / 仅媒体 / 无法核实 / 重复 / 受限），显示每项核验检查与最终类别；条目写入第 1 步；"继续分析 →"演示增量补充运行（复用已有采集 → 行情刷新 → 增量检索 → 带入用户条目 → 重跑分析与预测），显示补充前/补充后，推理链新增"用户补充"步骤，预测记录出现 `user_supplement`（非主评分） |
| 股票详情 · ② 分析与推理 | `#/stock/{ticker}/reason` | 第 2 步：推理链逐步列出规则、结论与引用；点击引用跳到第 1 步对应条目并高亮；右侧为得出的当前解释 |
| 短期预测 | `#/forecast/{ticker}/{regular_60m|regular_to_close|next_regular_session}` | 切换目标；状态：已结算/待结算/弃预测/无法结算/休市/模型验证中；图上区分历史行情、发布时间、起算报价、预测终点区间；有效期与显示状态（当前/已被替代/已过期待结算/已结算，见 NVDA 至收盘与 AMD 60 分钟） |
| 待决事件 | `#/events/{ticker}?e={event_id}` | 时间线节点与证据；事件结果（情景）与股价预测分栏；历史类比（含放宽与样本不足）、事件结算规则（公开确认/法律生效）、条件预测（等待触发）、跨行业解读 |
| 预测回放 | `#/replay/{prediction_id}?step=1..5` | 播放/上一步/下一步；原始 JSON；第 5 步揭示真实结果与结算理由 |
| 研发后台 | `#/admin/{runs|datasets|params|validation|fva|shadow|approvals}` | `fva` = 预测对照：按槽位准确率、校准、漂移、大误差复盘、"对照如何改进模型"；模拟训练阶段推进、快照对比、参数对比、校准/混淆矩阵、影子测试、审批/驳回/回滚演练 |
| 运营 · 一键运行 | `#/ops/run?tk=NVDA` | 选证券/目标/模式/复用策略，点击运行：8 个步骤实时推进；演示场景含正常、输入无变化复用、失败重试、部分弃预测；可取消；运行历史 |
| 运营 · 新公司接入 | `#/ops/onboarding`、`#/ops/onboarding/{id}` | 输入代码新建接入；8 阶段推进；LLM 起草档案供审核；回填报告；checklist；受阻 → 豁免或降级为 peer_only |
| 运营 · 数据源健康 | `#/ops/sources` | 延迟、错误率、授权与验证状态；立即检查 |
| 运营 · 任务与告警 | `#/ops/jobs` | 队列计数、告警确认、死信重新入队 |
